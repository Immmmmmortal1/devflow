# 全局规则（dev-flow global rules）

> 本文件由 dev-flow 在 session start / read-rules 时全文打印到 stdout，
> 是所有 dev-flow 会话必须遵守的全局规则。修改需提交到 devflow 仓库 git。

## 代码改动

- 最小化 diff，只改必要部分；不顺手重构无关代码。
- 提交前必须运行相关测试并确认通过，禁止只做多静态检查就宣称完成。
- 每个改动完成后保持工作区干净（commit 后再开始下一项）。

## 验证纪律

- UI / 状态类改动必须在真机上经 DebugBridge 验收，禁止模拟器回退。
- 禁止用截图或"看起来对"作为通过证据；以门禁脚本记录的证据为准。
- 测试禁止 mock 掉被测逻辑；测试脚本本身也要能真实运行。

## 安全

- API Key / 账号 / 服务器 / 邮箱等敏感信息统一查 `~/work/_knowledge/.secrets/`，
  严禁复制到项目文件或提交 git。
- 环境变量、令牌不得写入门禁证据、报告或日志输出。

## 错误与学习

- 遇到报错先查教训库（`cd ~/work/_knowledge && python3 lessons.py search <关键词>`），
  确认是否已知教训再动手。
- 犯了新错误、踩了新坑，任务结束后沉淀教训卡。

## 项目规则

- 各项目独有规则记录在该项目 `.dev-flow/rules.md`，每个门禁命令都会回带，
  与全局规则冲突时以更严格者为准。
